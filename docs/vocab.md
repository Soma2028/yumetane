# 語彙変換表

job tag の項目名（大人向け）→ 子ども向けの言い換え。

| job tag 項目 | 中学生向け | 小学生向け |
|---|---|---|

## 職業タグ

スワイプカードに表示する、職業の特徴タグ（1職業につき3つ）。画像がまだ無いため、
カードの情報量をこのタグが担う。

### データソースと候補プール

候補は2つの領域から、合計25項目。

- **仕事の性質**（job tagの39項目）から選定した19項目
- **RIASEC**（職業興味）6因子

RIASECは「向いている人の特性」、仕事の性質は「仕事の中身」で性質が異なるため、
1つのタグ欄に無制限に混ぜない。**RIASEC由来のタグは1職業につき最大1つまで**とし、
残り2つ以上は仕事の性質から選ぶ（`api/app/tags.py`の`select_tags`で実装）。

### 仕事の性質：19項目の選定基準

job tagの39項目から、以下の基準で19項目に絞った。残りの20項目はタグとして
選ばれないよう、そもそもデータに含めていない（`data/processed/jobs.csv`には
選定した19項目のzスコアしか無い）。

- **危険・不快・怪我・病気を想起させる項目は除外**（ミスの影響度、労働環境の負荷、
  暴力的な人々への対応、他者との身体的近接など）。子ども向けの発見アプリで
  不安を煽らない
- **抽象的・事務的すぎる項目は除外**（電話での会話、レターやメモの作成、機器等の
  速度に応じた作業、空調の有無、電子メールなど）。具体的にイメージできない
- **意味が重複する項目は1つに集約**（「反復作業」は「同一作業の反復」と、
  「優先順位や目標の自己設定」は「意思決定の自由」と、「対面での議論」および
  「意思決定が他者や企業に及ぼす影響力」は「他者とのかかわり」「他者と調整し、
  リードする」「意思決定の自由」とそれぞれ重複するため除外）
- **季節的（一年のうちの一定の時期だけ）は除外**。差別化への寄与が低い
- **競争水準は除外**。中学生に職業の魅力を伝えるタグとして、競争を前面に出す
  必要はないと判断した
- 「特殊な保護・安全装備の着用」は労働負荷寄りの項目だが、防護服・特殊装備は
  宇宙飛行士や消防士のように子どもにとって「かっこいい」文脈になりうるため、
  ポジティブな言い換えで残した

### カテゴリ分けと選定アルゴリズム

同じ軸のタグが3つのうち2つ以上を占めると、職業の輪郭がぼやける（例:
「座って集中」「立ち仕事」「歩き回る仕事」「外で働く」は全て「体の使い方」の軸）。
そのため19項目をカテゴリに分け、**同じカテゴリからは1職業につき1つまで**とする。

| カテゴリ | job tag項目 | タグ |
|---|---|---|
| 体の使い方 | 屋外作業 | 外で働く |
| 体の使い方 | 座り作業 | 座って集中 |
| 体の使い方 | 立ち作業 | 立ち仕事 |
| 体の使い方 | 歩行、走行 | 歩き回る仕事 |
| 対人 | 他者とのかかわり | 人と関わる |
| 対人 | グループやチームでの仕事 | チームで動く |
| 対人 | 外部の顧客等との接触 | お客さんと話す |
| 対人 | 他者と調整し、リードする | みんなをまとめる |
| 時間・予定 | 時間的切迫 | スピード勝負 |
| 時間・予定 | 規則的（ルーチンが決まっている） | 決まった予定で動く |
| 時間・予定 | 不規則（状況で変わる） | 毎日ちがう |
| 責任 | 結果・成果への責任 | 結果に責任を持つ |
| 責任 | 他者の健康・安全への責任 | 人の安全を守る |
| 精度・几帳面さ | 厳密さ、正確さ | 正確さが大事 |
| 精度・几帳面さ | 同一作業の反復 | コツコツ続ける |
| 自律性 | 意思決定の自由 | 自分で決められる |
| 道具・装備 | 特殊な保護・安全装備の着用 | 特別な装備を使う |
| 道具・装備 | モノ、道具、制御装置を扱う手作業 | 手先を使う |
| テクノロジー | 機械やコンピュータによる仕事の自動化 | 機械と働く |

RIASEC 6因子の言い換え（タグ用の短縮版。`api/app/explain.py`の説明文とは別）:

| RIASEC | タグ |
|---|---|
| 現実的 | ものづくり |
| 研究的 | しくみを調べる |
| 芸術的 | 表現する |
| 社会的 | 人を助ける |
| 企業的 | リーダーになる |
| 慣習的 | きちんと進める |

**選定アルゴリズム**: 25候補（仕事の性質19＋RIASEC6）をその職業でのzスコア降順に
並べ、上から順に「カテゴリが未使用の仕事の性質タグ」または「RIASECタグが
まだ選ばれていない場合のRIASECタグ」を貪欲に3つ選ぶ。RIASECタグは強制的に
1つ選ぶわけではなく、上位3件に自然に入らなければ0個のこともある。
